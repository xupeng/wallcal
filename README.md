# 墙上月历

适合打印在 A4 纸上的竖版中国月历，每月一页。包含农历、二十四节气、法定休假与调休上班信息，周一为每周首日。

需要 Node.js `20.19+` 或 `22.12+`（Vite 7 的运行要求）。

## 本地预览

```bash
npm install
npm run dev
```

在页面选择年份后，点击“打印 / 导出 PDF”。打印时请选择 A4、纵向、缩放 100%，并开启“背景图形”。

构建并预览静态产物：

```bash
npm run build
npm run preview
```

页面只会列出法定放假数据完整覆盖的 2004—2026 年。合法的 `?year=2026` 参数可以直接复现年份；无效或越界参数会回退到当前受支持年份，若当前年份超出范围则回退到最近的边界年份。

## 打印与 PDF

浏览器打印是普通用户的正式导出方式。打印设置请选择：

- 纸张：A4
- 方向：纵向
- 缩放：100%
- 边距：无（页面内部已保留 10—13 mm 安全区域）
- 选项：开启“背景图形”，关闭浏览器页眉和页脚

也可以用本机 Google Chrome 一次生成全年 PDF：

```bash
npm run build
npm run pdf -- 2026
```

文件会写入 `output/wallcal-2026.pdf`。法定节假日数据来自 [`chinese-days`](https://github.com/vsme/chinese-days)，当前支持 2004—2026 年；农历和节气支持 1900—2100 年。

CLI 会自动查找 Chrome、Edge 或 Chromium，并直接打开静态构建产物，不需要启动本地服务。在 Windows 上会检查 Chrome 与 Edge 的标准安装目录，也会从 `PATH` 查找 `chrome`、`msedge` 等命令。也可显式指定浏览器：

```bash
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
npm run pdf -- 2026
```

每次导出前 CLI 会删除同名旧文件，浏览器进程超过 120 秒会被终止；仅在本次生成的文件具有 PDF 签名且非空时报告成功。若提示缺少 `dist/index.html`，先运行 `npm run build`；若浏览器路径无效，CLI 会直接给出可操作的错误信息。

## 数据验证

```bash
npm test
```

自动化测试覆盖 2004—2026 每个年份的数据契约（全年天数、日期键、休假/补班数量、24 个节气、农历文本和状态互斥），以及周一开头的月份网格、关键法定假期、假期与节气重叠、调休补班白名单、农历初一和 CLI 导出保护。新增年份需先升级 `chinese-days` 并重新构建发布，不能预测尚未公布的放假安排。

## 设计说明

- 页面采用 10—13 mm 安全区域，在家用打印机的安全范围内尽量放大书写格。
- 淡红表示法定休假，淡紫表示节气；两者重叠时使用对角双色。
- “班”表示因调休需要上班。
- 屏幕端带年份切换与打印工具栏，打印时自动隐藏。
