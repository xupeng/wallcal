# 设计并实现 A4 竖版中国月历

## Goal

制作一套适合贴墙使用和手写记录的中国月历：每月一张 A4 竖版页面，可稳定导出为打印友好的 PDF，并在尽可能扩大日期格书写空间的同时准确呈现农历、二十四节气和中国法定放假/调休信息。

## Background and Confirmed Facts

- 用户希望获得“有设计感”且信息可靠的成品，而不只是日期计算示例。
- 中国使用习惯：每周从周一开始，周日为最后一列。
- 法定放假日期使用淡红底色；二十四节气日期使用淡紫色或效果更合适的低饱和强调色。
- 页面必须为 A4 竖版，每月独立成页，保留合理打印安全边距。
- 日期格的首要用途是手写事项，因此装饰和辅助信息不能明显侵占书写区域。
- 当前仓库已有一版待纳入正式任务检查和迭代的原型：Vite 单页应用、`chinese-days` 日历数据、浏览器打印入口、Chrome PDF 导出脚本及 2026 年示例 PDF。

## Requirements

### R1. 页面与打印

- 全年 12 个月各占一个独立 A4 纵向页面。
- 每页不得出现裁切、溢出或跨页断裂。
- 在常见家用/办公打印机安全边距内，日期格应尽可能大且保持完整网格。
- 屏幕控制栏不进入打印内容；打印时保留背景色。

### R2. 日期布局

- 一周七列，按周一至周日排列。
- 每月日期与星期位置正确，支持四至六行的自然月份布局。
- 非当月占位格保持克制，不展示容易误读的日期信息。

### R3. 日期信息

- 每个有效日期展示公历日号和农历日期。
- 农历初一优先显示月份名称，其他日期显示农历日名。
- 二十四节气当天展示节气名称，并使用节气强调底色。
- 国务院放假安排覆盖的日期显示假期名称和淡红底色。
- 调休补班日显示明确的“班”标记，但普通工作日不得显示。
- 假期和节气重叠时，两类信息均应可辨认。

### R4. 视觉与可用性

- 视觉风格简洁、温和、有纸品质感，适合长期贴墙。
- 日期数字、农历、节气和假期信息在普通 A4 彩色打印下可读。
- 浅色底纹不得明显妨碍黑色或深色笔迹。
- 页面包含简洁图例，解释放假、节气和调休标记。

### R5. 信息来源

- 农历、节气和放假安排使用可追溯的数据源，不手工推算。
- 产品只允许用户选择已有完整法定放假数据的年份；超出范围时不得暗示假期信息完整。

### R6. 生成器交互

- MVP 采用可重复使用的生成器，而不是固定交付单一年份文件。
- 用户可以从支持范围内选择年份，预览该年完整 12 个月，并导出全年 PDF。
- 切换年份后，月份日期、农历、节气、放假和补班信息必须同步更新。

### R7. 交付方式

- MVP 以本地部署的静态网页为主要交付形态。
- 日历计算和排版在浏览器端完成，不依赖运行时后端服务。
- 用户可通过项目说明在本机启动或预览构建产物；不要求配置公网托管。
- 用户通过浏览器原生打印能力保存为 PDF；项目可保留本地 CLI 批量导出作为开发辅助，但它不是普通用户的必经流程。
- 静态构建产物中的日历数据随版本发布；新增年份的国务院放假安排发布后，通过升级数据依赖并重新部署来支持。

## Acceptance Criteria

- [x] 导出的全年 PDF 恰好为 12 页，页面尺寸均为 A4 Portrait。
- [x] 抽查每个月 1 日的星期位置、当月天数和跨周排布，均与公历一致。
- [x] 抽查春节、清明、劳动节、端午、中秋、国庆及元旦安排，放假与补班标记和数据源一致。
- [x] 全年 24 个节气均在正确日期显示名称和节气底色。
- [x] 农历初一、除夕及若干随机日期的农历文本与数据源一致。
- [x] 普通工作日无“班”标记；全年“班”仅出现在官方调休补班日期。
- [x] 假期与节气重叠日期能同时识别两种语义。
- [x] 屏幕工具栏不出现在 PDF 中，所有月份无裁切、空白附加页或跨页断裂。
- [x] 日期格保留足够连续空白，可用常见水笔手写至少 2—3 行短事项。
- [x] 项目有清晰的本地预览、构建和 PDF 导出说明，并能按说明复现成品。

## Out of Scope

- 在线账户、云端保存或多人协作。
- 在页面中直接编辑和持久化事项。
- 节假日数据源尚未发布年份的预测性排班。
- A3、横版、周历、日历等其他版式。
- GitHub Pages、GitHub Actions 或其他公网发布与自动部署配置。
